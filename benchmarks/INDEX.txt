🚀 GUIA RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

PRIMEIRA VEZ? Leia isto:
  1. cat README.md                    ← Começar aqui
  2. cat BENCHMARKING_GUIDE.md        ← Entender o workflow
  3. bash BENCHMARK_QUICK_REFERENCE.sh ← Copiar comandos

VER ÚLTIMO RELATÓRIO:
  open outputs/comparison/benchmark_report.html  (macOS)
  xdg-open outputs/comparison/benchmark_report.html  (Linux)
  start outputs/comparison/benchmark_report.html  (Windows)

RODAR NOVO TESTE:
  bash BENCHMARK_QUICK_REFERENCE.sh

GERAR NOVO RELATÓRIO:
  cd scripts
  python generate_comparison_report.py --input-dir ../outputs/comparison/
